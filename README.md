# Vision-Guided Robot Arm (Graduation Project)

A 4-servo EEZYbotARM MK1-style robot arm that finds cubes and cylinders on a chessboard with a camera, classifies them, and sorts them into separate boxes. The vision pipeline is written by hand (no YOLO): homography + segmentation + contour/circularity classification.

## Architecture

```
Camera → Raspberry Pi 5 → UART → STM32F407G-DISC1 → I2C → PCA9685 → 4 servos
```

- **Raspberry Pi 5** (Python, OpenCV, pyserial): image processing, pixel → mm, inverse kinematics (lookup table), task planning.
- **STM32F407** (STM32CubeIDE, HAL): command parsing, joint-limit checks, synchronized smoothstep motion of all joints.
- **PCA9685** at 50 Hz drives the servos (base, shoulder, elbow, gripper).

## UART protocol (115200 8N1, lines end with `\n`, integer degrees)

| Pi → STM32 | STM32 → Pi |
|---|---|
| `P` | `PONG` |
| `M,base,shoulder,elbow,gripper[,ms]` | `OK`, then `DONE` when the motion ends |
| `H` (home 90,90,90,0) | `OK`, `DONE` |
| `S` | `POS,a0,a1,a2,a3,MOVING\|IDLE` |
| `X` | `STOPPED` |
| `D` | `DIAG,...` (PCA9685 / I2C / UART diagnostics) |

Errors: `ERR,BUSY`, `ERR,RANGE,<ch>`, `ERR,FORMAT`, `ERR,UNKNOWN`, `ERR,OVERFLOW`. The STM32 sends `READY` on boot.
